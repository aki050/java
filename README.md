# 🎋 おみくじアプリ

今日の運勢を占う、楽しいおみくじアプリ！  
Javaデスクトップ版とWebブラウザ版の2つのバージョンがあります。

---

## 📋 アプリの概要

- **名前を入力** → **「おみくじを引く」ボタンをクリック** → **運勢とラッキーアイテムが表示されます！**
- 運勢は 4 段階：大吉（10%）/ 中吉（20%）/ 小吉（40%）/ 凶（30%）
- ラッキーアイテムは5種類：桜 / バスケットボール / 時計 / 猫 / 本
- 毎回引くたびに新しい結果が生成されます

---

## 🚀 使い方

### 1️⃣ **Javaデスクトップ版**（Main.java）

```bash
# JDKがインストールされている環境で実行
cd /Users/aki/Documents/GitHub/java
javac Main.java
java Main
```

**特徴：**
- Swingフレームワークで実装
- ウィンドウアプリとして起動
- 名前をテキストフィールドに入力してボタンをクリック

---

### 2️⃣ **Webブラウザ版**（index.html）

```bash
# ブラウザで直接開く、または簡易サーバーで実行
# ファイルをダブルクリック、または
# VS Code の「Live Server」拡張機能を使用
```

**特徴：**
- モダンなWebUIデザイン
- グラデーション背景・カード風のレイアウト
- アニメーション付きで結果表示
- 履歴機能付き（セッション中の最大7件まで表示）
- 色分け表示（大吉：緑 / 中吉：青 / 小吉：オレンジ / 凶：赤）

---

## 🎨 Web版の機能詳細

### ✨ ビジュアル要素
- **和風タイトル設計**：和柄フォント、グラデーション背景
- **フェードインアニメーション**：結果が滑らかに表示
- **ホバー効果**：ボタンに浮き上がる感覚

### 🔧 ユーザーインタラクション
- 名前入力チェック（1〜20文字）
- リアルタイムエラーメッセージ
- アクセシビリティ対応（`aria-live`などの属性）

### 📊 履歴管理
- 引いた履歴がリアルタイムで表示
- タイムスタンプ付き
- セッション中のみ保持（ページ更新でリセット）
